# Internal Pistis iOS regression harness

The [qualification contract](../../docs/development/internal-ios-regression.md)
describes the source-only QR, onboarding and biometric tests, their modelled
effects and the remaining native, service and protected-admission gates.

Run `ios/RegressionHarness/run-source-regressions.sh` from the committed
candidate. Its [recipe](recipe.json) is not an approved Expedition task or a
release identity, and the script does not publish status.
