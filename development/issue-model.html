Planning issue model

The canonical sources remain PROJECT_CHARTER.md, MILESTONE.md, and TODO.md. GitHub mirrors them as a navigable execution graph:

  • Epics represent the sixteen TODO domains.

  • Features group related outcomes within an epic.

  • Tasks correspond one-to-one with atomic TODO items.

  • Subtasks are checklists inside task issues and are scoped below four hours.

Identifiers use PIS-E##, PIS-E##-F##, and PIS-E##-F##-T##. Dependencies are explicit in every issue. Tasks are ordered within their feature unless the issue states that work may proceed in parallel.
